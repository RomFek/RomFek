## What I work on

- **Data modelling:** dbt and BigQuery, from raw sources to documented, tested
  models for Finance, CRM, Marketing and Content teams
- **Performance and cost:** incremental models, partitioning and caching
  strategies that keep pipelines fast and cheap as data grows
- **Semantic layer and BI:** Looker (LookML, administration through the API),
  consistent metric definitions
- **AI-ready data:** documented metrics and domain context so AI agents can
  answer stakeholder questions without guessing
- **Python:** automation, scrapers and admin tooling
